# 产品影片页面接入

首页主入口下方增加「观看 45 秒演示」，打开公开路由 `/film`。不在首页挂载播放器，不自动弹窗、不自动播放、不在首页请求 MP4。影片页使用原生视频控件，提供章节、返回首页与进入平台入口。进入影片页临时停止环境音，离开时遵循原环境音偏好恢复。

成片和封面保存在 `web/public/media/`，Vite 构建与现有 web Dockerfile 会自动包含它们。视频约 9.5 MB，无额外视频服务或外站嵌入依赖。Nginx `/media/` 返回实际文件，缺失时返回 404，避免将首页 HTML 误当视频返回；支持原生字节范围请求。

## 发布

沿用项目既定的腾讯云/现有站点发布流程，重新构建并发布 web 服务即可。公网入口为现有网站域名加 `/film`，无需修改后端或数据库。静态托管则发布 `web/dist/` 全目录，并为 `/film` 等前端路由配置 index.html 回退。

当前未执行公网发布：本地部署配置仍指向 localhost，尚无可用的目标服务器或线上网址。`http://127.0.0.1:4173/` 为当前电脑的生产构建预览，不能作为异地评委访问地址。
